Key Data Flows
📅
Booking Flow: Customer fills form → Stripe/PayPal charges deposit → Webhook fires → Supabase creates job record → Twilio sends confirmation SMS + Resend sends email → Job appears in admin dash and sweeper queue.
✅
Job Complete Flow: Sweeper marks complete in app → Supabase updates job status → Photos move to customer-accessible storage bucket → Twilio fires "job complete" + review request SMS → Admin dash reflects instantly via Supabase Realtime.
★
Membership Flow: Customer picks annual ($249) or monthly ($24/mo) at checkout → Stripe creates subscription + customer → Webhook activates Storm Ready status in Supabase profiles table → Customer portal shows member benefits → Stripe handles all future billing automatically.

1 · AI Photo Pre-Screening Tool
🤖
How it works: Customer uploads 1–2 shelter photos during booking. A Next.js API route sends the image to Claude's vision model with a grading prompt. Grades A/B auto-approve. Grade C triggers admin review within 2 hours. D/F pause the booking and notify admin immediately. All results stored on the booking record in Supabase.
// /api/photo-screen/route.ts import Anthropic from '@anthropic-ai/sdk' export async function POST(req: Request) { const { imageBase64, mediaType, bookingId } = await req.json() const client = new Anthropic() const response = await client.messages.create({ model: 'claude-sonnet-4-5', max_tokens: 1024, messages: [{ role: 'user', content: [ { type: 'image', source: { type: 'base64', media_type: mediaType, data: imageBase64 } }, { type: 'text', text: `Grade this storm shelter photo A–F. Respond ONLY in JSON: { "grade": "A|B|C|D|F", "approved": true|false, "flags": ["excessive_junk","standing_water","structural_damage","mold_walls","rodent_evidence"], "surcharge_suggested": true|false, "surcharge_amount": 0|35|50|75, "admin_note": "brief note for admin", "customer_message": "friendly message for customer" } A=clean/minor dust · B=manageable items · C=moderate junk (admin review) D=excessive furniture/bags (pause+contact) · F=hazard present (admin call)` } ] }] }) const result = JSON.parse(response.content[0].text) // Store result on booking record in Supabase await supabase.from('bookings').update({ photo_grade: result.grade, photo_flags: result.flags, photo_approved: result.approved, photo_surcharge: result.surcharge_amount, photo_admin_note: result.admin_note }).eq('id', bookingId) // Notify admin if C, D, or F grade if (['C', 'D', 'F'].includes(result.grade)) { await notifyAdmin(bookingId, result) } return Response.json(result) }

2 · TikTok Integration
🎵
Architecture: Sweeper uploads before/after video clips → stored in Supabase Storage (job-videos bucket) → admin reviews in marketing panel → one-click "Publish to TikTok" triggers Content Posting API → video goes live. Same video pushed to Instagram Reels via Meta Graph API. Analytics synced back weekly into the admin marketing panel.
// /api/tiktok/publish/route.ts export async function POST(req: Request) { const { videoStoragePath, caption, jobId } = await req.json() // 1. Get signed video URL from Supabase Storage (1hr expiry) const { data: signedUrl } = await supabase.storage .from('job-videos').createSignedUrl(videoStoragePath, 3600) // 2. Init TikTok upload via Content Posting API const initRes = await fetch('https://open.tiktokapis.com/v2/post/publish/video/init/', { method: 'POST', headers: { 'Authorization': `Bearer ${process.env.TIKTOK_ACCESS_TOKEN}` }, body: JSON.stringify({ post_info: { title: caption, privacy_level: 'PUBLIC_TO_EVERYONE' }, source_info: { source: 'PULL_FROM_URL', video_url: signedUrl.signedUrl } }) }) const { data } = await initRes.json() // 3. Log to social_posts table for analytics tracking await supabase.from('social_posts').insert({ job_id: jobId, platform: 'tiktok', publish_id: data.publish_id, caption, video_path: videoStoragePath, published_at: new Date().toISOString() }) return Response.json({ success: true, publish_id: data.publish_id }) }

3 · Sweeper Onboarding Portal
🧹
4-step flow: Apply form → tool photo uploads → IC agreement e-sign (DocuSeal) → pending confirmation. Admin reviews in /admin/sweepers dashboard → approves → Supabase account auto-created with role: sweeper → welcome SMS sent → sweeper sees jobs immediately in app.
// /api/sweepers/approve/route.ts export async function POST(req: Request) { const { applicantId } = await req.json() // Fetch applicant record const { data: applicant } = await supabase .from('sweeper_applicants').select('*').eq('id', applicantId).single() // Create Supabase auth user const tempPassword = generateSecurePassword() const { data: { user } } = await supabase.auth.admin.createUser({ email: applicant.email, password: tempPassword, email_confirm: true }) // Create profile with sweeper role await supabase.from('profiles').insert({ id: user.id, role: 'sweeper', full_name: applicant.full_name, phone: applicant.phone, approved_at: new Date().toISOString() }) // Mark applicant as approved await supabase.from('sweeper_applicants') .update({ status: 'approved', profile_id: user.id }) .eq('id', applicantId) // Send welcome SMS with login details await sendSMS(applicant.phone, `Welcome to Storm Sweep! 🌪️ You're approved. Log in at stormsweep.com/sweeper — temp password: ${tempPassword}. Change it on first login. Questions? Reply here.` ) return Response.json({ success: true }) }
